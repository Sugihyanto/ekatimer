# Changelog

## 1.0.28 — modified release (2026-08-24)

- Added independent multiple profiles with profile-scoped timer sessions,
  history, statistics, CSV, and Excel data.
- Added optional decimal Quality input from `0.0` through `5.0`.
- Added five fractionally filled stars for Quality values such as `3.5`.
- Added optional notes after completion and full note display without ellipsis.
- Added direct per-session editing of date, time, duration, Quality, and notes.
- Improved session rows so start/end stays on one line and duration appears on
  the following line.
- Added Calendar/Bar Chart report selection and weekly/monthly Quality toggles.
- Added JSON backup for all profiles and sessions.
- Added Merge, Overwrite, and Cancel choices for JSON and CSV imports.
- Added deterministic handling of duplicate and conflicting imported records.
- Added Excel export and expanded Quality/notes in reports and exports.
- Retained the original Android application ID `org.tipitakapali.ekatimer`
  and renamed the visible app to `Meditation Timer`.
- Retained the original launcher artwork and expanded selected quote
  collections.

## 1.0.20 — upstream baseline

- Original Meditation Timer timer modes, bells, interval signals, vibration, alarm,
  notifications, widgets, history, CSV, and core statistics.
- Upstream source: https://github.com/vpnry/ekatimer
- Baseline commit: `0acc5e58a93c7b8082d4dab5e440468b4a599197`.
