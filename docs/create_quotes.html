📖 Format Guide

Each non-empty line becomes one quote in the generated JSON. The file will have the same structure as Meditation Timer's built-in quotes:

  • Every line is wrapped as a JSON string in an "en" array
  • Empty lines are automatically skipped
  • Leading/trailing whitespace is trimmed from each quote
  • Duplicate lines are not removed — each line stays as-is

The generated file looks like this:

{
    "en": [
        "Just as a fine horse is stirred...",
        "You yourselves must make the effort..."
    ]
}
