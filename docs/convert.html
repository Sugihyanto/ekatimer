DIY: Convert your session data to Meditation Timer format (ekatimer_sessions.csv):

id — Auto-generated UUID for each session
startTime — Session start time (ISO 8601)
endTime — Session end time (ISO 8601)
durationSeconds — Actual duration in seconds
targetDurationSeconds — Planned duration in seconds (same as durationSeconds)
timerMode — Timer mode: timed | endAt | unlimited
completed — 1 session completed as planned | 0 stopped early
notes — Optional session notes
